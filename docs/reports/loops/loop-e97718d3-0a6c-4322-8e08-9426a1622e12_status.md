## QA findings and integration risks

- Current `origin/dev` has no `src/ta_model/models`, `training`, or `registry` modules; S7 must create reusable contracts rather than ad hoc scripts.
- Current dependencies do not include MLflow, PyTorch, scikit-learn, or LightGBM. Any addition must be pinned, reflected in `uv.lock`, and documented with Docker/profile impact.
- Current Compose has only `stream` profile Redpanda services. MLflow registry work must use the approved PostgreSQL/MinIO/MLflow/core/research stack or stop for ADR/human sync.
- Lookahead leakage is the primary stop-the-line risk: training transforms, normalization, labels, ablations, and calibration must respect chronological split boundaries and event-time availability.
- Model evidence must not become gross-only or predictor-only. Reports must include probabilistic metrics, calibration, uncertainty/quantile coverage, and baseline comparison.
- No auto-promotion: registry state transitions must remain gated, auditable, and owner-reviewed; rollback metadata is mandatory for candidate/champion records.
- Hugging Face/large checkpoint use is not needed for the first candidate. If introduced, it must obey revision/license/offline artifact/token guardrails and must not add a new runtime path.
